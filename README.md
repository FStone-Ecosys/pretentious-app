# Pretentious App

> *An exercise in deliberate over-engineering and aesthetic superiority.*

This is a minimal, single-file web application designed to be **pretentious**.

It does almost nothing. It does it with great ceremony.

## Features

- A button that does nothing, but feels important.
- A counter that counts your pretension.
- Dark mode, because light mode is for the masses.
- No dependencies. No frameworks. No compromises.

## Run it

Just open `index.html` in your browser.

```bash
open index.html
```

Or serve it locally:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Philosophy

Why build something useful when you can build something *impressive*?

This app exists to demonstrate that simplicity, when dressed in the right words, becomes sophistication.
